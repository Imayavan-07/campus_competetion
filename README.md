# Campus Competition (UniSync)

This repository is organized into frontend and backend applications.

## Directory Structure

```
.
├── backend/    # Backend server / APIs
└── frontend/   # React + Vite + TypeScript frontend application
```

## Getting Started

### Frontend

Navigate to the `frontend` directory:

```bash
cd frontend
npm install
npm run dev
```

To build for production:

```bash
npm run build
```

### Backend

Navigate to the `backend` directory:

```bash
cd backend
```
